# CodexNeo Implementation List

Use this file as the intake list for features, modifications, and updates before implementation starts.

## Workflow

1. Add each requested item under **Requested Items**.
2. Mark ambiguous items as **Needs Clarification** until the behavior is explicit.
3. When the list is ready, ask Codex to implement.
4. Implementation should follow TDD, update OpenSpec when behavior changes, update the root handover after each change, and verify before reporting completion.

## Status Legend

- `Intake`: requested but not analyzed yet.
- `Needs Clarification`: blocked on exact expected behavior or owner-controlled value.
- `Ready`: clear enough to implement.
- `In Progress`: currently being implemented.
- `Verified`: implemented and verified.
- `Superseded`: replaced by a later verified implementation.
- `Deferred`: intentionally postponed.
